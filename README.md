# MultiView

Watch many YouTube streams on one screen, with live chat, custom controls,
a focus layout and a saved channel list.

## Run it

1. Copy `config.example.js` to `config.js` and add your YouTube Data API key
   (optional: without a key the app works, but without channel pictures).
2. Serve the folder, for example with VS Code Live Server or
   `python -m http.server 8000`.
3. Open the page and click **+ Add stream**.
